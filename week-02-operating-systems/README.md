# Week 2: Operating Systems and Standardization

## Status

In progress

## Overview

This week turns the approved laboratory design into a controlled
implementation.

The focus is not merely installing operating systems. The focus is defining
their desired state, implementing that state consistently, verifying the
result, identifying deviations, and maintaining accurate records.

## Central Principle

> Installation creates a system. Standardization makes the system manageable.

## Learning Objectives

By the end of this week, I should be able to:

- Select a virtualization platform against documented requirements
- Plan and implement a controlled change to the host
- Define the desired state of a virtual machine before creating it
- Explain the difference between installation and standardization
- Install and configure Windows and Linux virtual machines
- Verify operating-system identity, resources, networking, and updates
- Compare actual configuration against an approved baseline
- Identify and document configuration drift
- Record deviations without hiding unsuccessful results
- Update inventory and architecture documentation after implementation
- Establish a repeatable system-build procedure
