## Virtualization Assessment

The following questions must be answered:

- [ ] Does the processor support hardware virtualization?
- [ ] Is hardware virtualization enabled?
- [ ] Is a hypervisor already installed?
- [ ] Is sufficient memory available for multiple virtual machines?
- [ ] Is sufficient storage available for virtual disks and snapshots?
- [ ] Can an isolated virtual network be created?
- [ ] Can the workstation be backed up before major changes?
