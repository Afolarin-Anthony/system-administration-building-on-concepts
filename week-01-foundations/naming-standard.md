# Laboratory Naming Standard

## Purpose

This document establishes consistent naming conventions for laboratory assets.

The goal is to improve identification, documentation, troubleshooting, and inventory management.

## Naming Principles

Names should be:

- Unique
- Predictable
- Readable
- Consistent
- Meaningful

Names should avoid:

- Personal jokes
- Ambiguous abbreviations
- Random numbers
- Temporary descriptions
- Operating-system version numbers

## Device Naming Format

```text
LAB-[ROLE]-[NUMBER]
```

Examples:

```text
LAB-WIN-01
LAB-LNX-01
LAB-DC-01
LAB-CLI-01
```

## User Naming Format

```text
firstname.lastname
```

Examples:

```text
anthony.admin
john.user
mary.finance
```

## Group Naming Format

```text
GRP-[FUNCTION]
```

Examples:

```text
GRP-ADMINS
GRP-IT
GRP-FINANCE
```

## Network Naming Format

```text
LAB-NET-[NUMBER]
```

Examples:

```text
LAB-NET-01
```

## Documentation Naming Format

```text
YYYY-MM-DD-topic.md
```

Example:

```text
2026-10-04-workstation-assessment.md
```

## Benefits

Consistent naming:

- Simplifies troubleshooting
- Improves inventory management
- Improves documentation
- Reduces confusion
- Supports automation
