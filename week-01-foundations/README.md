# Week 1: Systems Administration Foundations and Laboratory Setup

## Status

Completed


## Overview

This week establishes the foundation for the System Administration: Building on Concepts course.

The work focuses on understanding the responsibilities of a systems administrator, assessing the administration workstation, designing an isolated virtual laboratory, and establishing standards for naming, documentation, security, and evidence collection.

## Learning Objectives

By the end of this week, I should be able to:

- Explain the responsibilities of a systems administrator
- Identify the major components of a systems administration environment
- Collect and interpret basic workstation information
- Evaluate whether a workstation can support a virtual laboratory
- Design a small virtual systems administration laboratory
- Establish consistent device and account naming conventions
- Create a basic asset inventory
- Document technical work using a reproducible structure
- Protect sensitive information when publishing technical evidence
- Use Git and GitHub to record project progress

## Core Concepts

The primary concepts for this week are:

- Systems administration
- Configuration management
- Standardization
- Virtualization
- Documentation
- Inventory management
- Change tracking
- Laboratory isolation
- Evidence collection
- Security and privacy

## Laboratory Goal

The goal is to design and prepare a safe virtual environment for practising Windows and Linux administration.

The initial laboratory is expected to contain:

- One physical administration workstation
- One virtualization platform
- One Windows client virtual machine
- One Linux server virtual machine
- One internal or isolated virtual network

Additional systems will be introduced only when required by future projects.

## Safety Rules

- Only authorized systems will be administered.
- Experiments will be conducted in an isolated laboratory.
- Passwords, tokens, private keys, and recovery codes will not be published.
- Screenshots and command output will be reviewed before publication.
- Personal and device-identifying information will be removed when unnecessary.
- Real organizational information will not be used without authorization.
- Fictional names and scenarios will be used for laboratory exercises.
