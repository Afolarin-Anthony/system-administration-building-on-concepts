# Security Policy

## Reporting a Security Concern

If this educational repository accidentally exposes sensitive information, please report the concern privately to the repository owner.

Do not create a public issue containing passwords, tokens, private keys, personal information, or details that could increase the exposure.

## Repository Security Rules

The repository must not contain:

- Passwords
- Authentication tokens
- Private keys
- Recovery codes
- Personal information
- Confidential organizational information
- Unauthorized production configurations
- Unredacted security findings

Laboratory evidence must be reviewed and sanitized before publication.
